**Contexto:**
Este código é a etapa de RECUPERAÇÃO (retrieval) de um pipeline RAG para a empresa NovaTech.
Já existe o script `indexar_documentos.py` que populou um ChromaDB local (coleção `"novatech_docs"`,
pasta `./chroma_db`) usando `SentenceTransformerEmbeddings` com o modelo `all-MiniLM-L6-v2`.
Os chunks armazenados possuem os metadados: `source`, `doc_id`, `versao`, `data_emissao`,
`responsavel`, `chunk_index`, `total_chunks`.

**Tarefa:**
Crie uma função Python chamada `buscar_chunks` em um arquivo chamado `retriever.py`,
que será importada e chamada dentro do mesmo pipeline que já instanciou o ChromaDB
e o modelo de embedding — portanto, a função deve receber esses objetos como parâmetros,
não instanciá-los internamente.

**Assinatura da função:**

def buscar_chunks(
    pergunta: str,
    vectorstore: Chroma,
    embedding_model: SentenceTransformerEmbeddings,
    n: int = 5,
    score_minimo: float = 0.35,
    filtro_metadados: dict | None = None
) -> list[dict]:

**Comportamento esperado:**
1. Gerar o embedding da `pergunta` usando o `embedding_model` recebido por parâmetro
2. Buscar os chunks mais similares no `vectorstore` usando `similarity_search_with_relevance_scores`
3. Retornar no mínimo 3 resultados (se existirem no banco), ordenados por score decrescente
4. Descartar chunks com score abaixo de `score_minimo` (padrão: 0.35)
5. Se `filtro_metadados` for fornecido (ex.: `{"responsavel": "Diretoria Comercial"}`),
   aplicar como filtro `where` na query do ChromaDB
6. Se nenhum chunk atingir o score mínimo, retornar lista vazia e exibir:
   `[RETRIEVER] Nenhum chunk relevante encontrado para a pergunta.`

**Formato de retorno — lista de dicionários:**
Cada item da lista deve ter exatamente esta estrutura:

{
    "chunk_index_global": int,     # posição no ranking (0 = mais similar)
    "score": float,                # score de similaridade (0.0 a 1.0)
    "texto": str,                  # conteúdo do chunk
    "source": str,                 # nome do arquivo de origem
    "doc_id": str,                 # id do documento
    "versao": str,                 # versão do documento
    "data_emissao": str,           # data de emissão/atualização
    "responsavel": str,            # responsável pelo documento
    "chunk_index": int,            # índice do chunk dentro do documento
    "total_chunks": int,           # total de chunks do documento
    "abaixo_do_limiar": bool       # True se o score estiver abaixo do score_minimo
}

**Requisitos técnicos:**
- Use `similarity_search_with_relevance_scores` do LangChain Chroma (retorna tuplas `(Document, score)`)
- Solicite `n * 2` resultados ao ChromaDB antes de filtrar por score, para garantir margem
  suficiente para atingir o mínimo de 3 após o filtro
- Se após o filtro de score restar menos de 3 resultados, inclua os próximos melhores
  (mesmo abaixo do score mínimo) até completar 3, marcando-os com `"abaixo_do_limiar": True`
- Ordene sempre por `score` decrescente antes de retornar
- Adicione type hints completos em toda a função
- Trate exceção de conexão com ChromaDB com `try/except` e relance com mensagem clara
